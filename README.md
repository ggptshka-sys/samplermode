# SamplerMode для REAPER 6 и NVDA

SamplerMode — 64-разрядный семплер Windows для **REAPER 6 x64**. Плагин создан как VST3-модуль `sampler.dll`; REAPER 7 не требуется. Интерфейс построен из стандартных элементов управления Windows и содержит доступные имена для NVDA.

## Установка без сборки исходников

1. Откройте страницу [Releases](https://github.com/ggptshka-sys/samplermode/releases/latest).
2. Скачайте `SamplerMode-Setup-1.0.0.exe` (в следующих версиях номер будет другим).
3. Запустите установщик и подтвердите запрос администратора Windows. Установщик пока не имеет коммерческой цифровой подписи, поэтому Smart Screen может показать предупреждение: проверьте имя файла и источник GitHub, затем выберите «Подробнее → Выполнить в любом случае».
4. Закройте и снова запустите REAPER 6 x64.

Установщик размещает файлы здесь:

- требуемый модуль: `C:\Program Files\VST Plugins\sampler.dll`;
- копия для автоматического обнаружения REAPER: `C:\Program Files\Common Files\VST3\sampler.vst3`;
- программа диагностики и обновление: `C:\Program Files\SamplerMode`;
- демонстрационная библиотека: `Документы\SamplerMode\Example Library`.

Обычно дополнительная настройка не нужна: REAPER 6 автоматически сканирует стандартную папку VST3. Если SamplerMode не появился, откройте **Options → Preferences → Plug-ins → VST**, нажмите **Re-scan** или **Clear cache/re-scan** и убедитесь, что в путях есть `C:\Program Files\Common Files\VST3`. В списке инструментов выбирайте **SamplerMode (VST3)**, разработчик SamplerMode.

> Нужна 64-разрядная версия REAPER 6. 32-разрядный REAPER этот плагин не загрузит.

## Работа с клавиатуры и NVDA

- `Tab` и `Shift+Tab` — переход между элементами.
- Стрелки влево и вправо — изменение движка.
- Стрелки или `Alt+Стрелка вниз` — выбор пункта выпадающего списка.
- `Enter` или `Пробел` — нажатие кнопки «Выбор библиотеки».
- Путь к библиотеке и статус загрузки доступны как поля только для чтения.

Для начала работы нажмите **«Выбор библиотеки»**, выберите папку, затем в списке **«Файл конфигурации»** выберите нужный TXT. Если в папке один или несколько TXT, первый файл загружается автоматически. Статус сообщает число загруженных сопоставлений и первое предупреждение об ошибке.

Путь к библиотеке, имя конфигурации и параметры сохраняются в проекте REAPER. Сами WAV-файлы в проект не копируются: не перемещайте библиотеку после сохранения проекта.

## Параметры

| Параметр | Диапазон и начальное значение |
|---|---|
| Громкость | от −60 до +12 дБ; по умолчанию 0 дБ |
| Панорама | от −100 (влево) до +100 (вправо); по умолчанию 0 |
| Атака | 1–5000 мс; по умолчанию 10 мс |
| Декей | 1–5000 мс; по умолчанию 100 мс |
| Сустейн | 0–100 %; по умолчанию 100 % |
| Релиз | 1–10000 мс; по умолчанию 100 мс |
| Педаль сустейна | `Pedal Off` или `Pedal On`; по умолчанию `Pedal Off` |
| Диапазон питч-бенда | 1–12 полутонов вверх и вниз; по умолчанию 1 |
| Колесо модуляции | `Mod Off`, `Cut Off`, `Vibrato`; по умолчанию `Mod Off` |

При `Pedal Off` отпускание MIDI-клавиши запускает стадию релиза. При `Pedal On` обычные ноты продолжают звучать после отпускания клавиши; при возврате в `Pedal Off` удержанные ноты переходят в релиз.

`Cut Off` управляет низкочастотным фильтром: от примерно 200 Гц при нулевом положении колеса до 20 кГц при максимальном. `Vibrato` создаёт вибрато частотой 5,5 Гц и глубиной до четверти тона в каждую сторону.

## Создание собственной библиотеки

Структура папки:

```text
Acoustic Guitar\
    Acoustic Guitar.txt
    Samples\
        034_C_down_1.wav
        034_C_down_2.wav
```

В корне может быть несколько TXT-файлов — они появятся в списке конфигураций. Кодировка рекомендуется **UTF-8**. Пустые строки и строки, начинающиеся с `#` или `;`, являются комментариями.

Пример одной строки:

```text
File name:034_C_down_1.wav=but0 not034 vel030-127 vol-15db mut000 out1/2 File name:034_C_down_2.wav=but1 not034 vel030-127 vol-30db mut000 out1/2
```

Каждую сопоставление удобнее писать на отдельной строке, но несколько конструкций `File name:` в одной строке тоже поддерживаются.

| Параметр | Значение |
|---|---|
| `but` | `but0` — нажатие; `but1` — отпускание |
| `not` | MIDI-нота 001–127; семпл назначается на эту ноту |
| `vel` | Диапазон velocity 000–127, например `vel030-127` |
| `vol` | Громкость семпла от −140 до +12 дБ, например `vol-15db` |
| `mut` | Нота 001–127, которую нужно заглушить; `mut000` отключает глушение |
| `out` | Стереопара: `out1/2`, `out3/4`, …, `out15/16` |

Пример закрытого хэта на ноте 61, глушащего открытый хэт на ноте 62:

```text
File name:061_closed_hat.wav=but0 not061 vel000-127 vol-09db mut062 out1/2
File name:062_open_hat.wav=but0 not062 vel000-127 vol-09db mut000 out1/2
```

Для семпла `but1` диапазон velocity проверяется по исходному нажатию, поэтому обычное отпускание клавиши с нулевой velocity не мешает его запуску. Если на одну ноту подходят несколько сопоставлений, они воспроизводятся одновременно как слои.

Поддерживаются моно- и многоканальные WAV: PCM 8/16/24/32 бит, float 32/64 бит. У многоканальных файлов используются первые два канала. Подкаталоги внутри `Samples` разрешены. Частота дискретизации WAV может отличаться от частоты проекта.

Основной выход `out1/2` работает на обычной стереодорожке. Для остальных выходов в REAPER установите дорожке 16 каналов и настройте соединения выходов плагина. Один экземпляр предоставляет восемь стереопар.

## Проверка без REAPER

Установка включает `sampler-diagnostic.exe`. Она загружает настоящую библиотеку, запускает первый семпл через звуковой движок и записывает результат WAV. Пример для командной строки:

```bat
cd /d "C:\Program Files\SamplerMode"
sampler-diagnostic.exe "%USERPROFILE%\Documents\SamplerMode\Example Library" "Demo.txt" "%USERPROFILE%\Desktop\sampler-check.wav"
```

Результат `ОК` означает, что конфигурация прочитана, WAV загружен и сформирован ненулевой звуковой сигнал. Полученный `sampler-check.wav` можно прослушать. Это проверяет библиотеку и DSP, но не заменяет проверку MIDI, сканирования плагина и NVDA в REAPER 6.

Для окончательной проверки нужен именно REAPER 6 x64. Можно использовать переносимую установку, не меняя основную конфигурацию: [официальный установщик REAPER 6.83 x64](https://www.reaper.fm/files/6.x/reaper683_x64-install.exe), при установке выбрать **Portable install**.

## Обновление

1. Сохраните проект и закройте REAPER.
2. В меню «Пуск» откройте **SamplerMode → Обновить SamplerMode**.
3. Программа проверит GitHub, скачает новый установщик, сверит SHA-256 и попросит подтвердить установку администратором.

Если обновление не скачалось или контрольная сумма не совпала, установка не выполняется и прежняя версия остаётся на месте.

Разработчику для выпуска обновления нужно изменить версию в `CMakeLists.txt`, `installer.iss`, `Update.ps1` и версии класса в `src/plugin.cpp`, создать тег `vX.Y.Z` и отправить его в GitHub. Workflow `.github/workflows/release.yml` соберёт и опубликует релиз автоматически.

## Сборка из исходников

Требуются Windows, Visual Studio 2022 Build Tools с рабочей нагрузкой C++, CMake и Inno Setup 6. VST3 SDK загружается CMake автоматически с зафиксированной версии.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
iscc .\installer.iss
```

Результаты:

- `build\package\sampler.dll` — плагин;
- `build\package\sampler-diagnostic.exe` — диагностика;
- `release\SamplerMode-Setup-1.0.0.exe` — установщик.

Официальная проверка VST3 после сборки:

```bat
build\bin\Release\validator.exe build\VST3\Release\sampler.vst3
```

## Ограничения текущей версии

- Windows x64, VST3, 32-разрядные аудиобуферы хоста; REAPER 6 поддерживает этот режим.
- До 64 одновременно звучащих голосов.
- Одна MIDI-нота на семпл; автоматическое растягивание семпла по диапазону клавиш не выполняется.
- Loop, round-robin и автоматический импорт других форматов семплеров пока не реализованы.
